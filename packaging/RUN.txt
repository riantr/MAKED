MAKED
=====

This archive holds a prebuilt MAKED: one executable and the browser files it
serves. Nothing else is needed -- no MoonBit toolchain, no compiler, no
package manager.

Run it from this directory:

    ./server              (Windows: server.exe)

Then open <http://127.0.0.1:8080/>.

The database is created next to the executable on first run, seeded with the
site's own pages. Your own records live in the same file, so keep a copy of
it if you want to keep them.

Useful settings, all optional:

    MAKED_PORT       the port to listen on          (default 8080)
    MAKED_HOST       the address to listen on       (default 127.0.0.1)
    MAKED_DB         where the database lives        (default maked.db)
    MAKED_DIST       where the browser files live    (default frontend/dist)

MAKED_HOST is the one to reach for when the server has to be reachable from
another machine: the default, 127.0.0.1, means this computer only.

MAKED runs on four files as well, and each is named by a variable of its own.
All four are optional: leave one unset and MAKED runs on the built-in one.

    MAKED_MODEL      the machine: the domains, positions, slots and rules
    MAKED_RESEARCH   the mapping table: what a document means
    MAKED_SOCIETY    the society vocabulary: the collective's own words
    MAKED_CORPUS     the corpus: where the documents come from

This archive carries examples of all four: machines under models/, mapping
tables and corpora under research/, and research/notes/ is the corpus one of
those corpora names. Point a variable at one of them to run on it.

There is no authentication. Anyone who can reach the port can read and delete
every record, so do not expose it to a network you do not control.

The source is at <https://github.com/riantr/MAKED>.
