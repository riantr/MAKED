# MAKED runtime dependencies.
#
# Modernised from the 2019 stack (Django 2.1.8 / django-cms 3.6), which could
# not be installed on a supported Python. The current target is Django 5.2 LTS
# (supported until April 2028) with django CMS 5.1.
#
# Install with:  pip install -r requirements.txt
#
# Two packages present in the original requirements.txt are deliberately gone:
#
#   django-mdeditor / django-markdown-deux
#       Unmaintained, no release compatible with Django 4+. The article body
#       field is now a plain TextField and Markdown is rendered in the view.
#   django-parler / django-mptt
#       Transitive dependencies of the old djangocms-* plugins, which are no
#       longer used here.
#
# djangocms-snippet was also dropped: version 5.x hard-depends on
# djangocms-versioning (which must be a separately installed app with its own
# settings), and the original site stored zero snippets.
